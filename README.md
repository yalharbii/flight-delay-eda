Predicting Flight Delays Across U.S. Airports

This repository hosts the code for my CSE 163 Summer 2026 final project. Final project implements prediction on Vega flights_10k
dataset, which is a 10,000-flight sample derived from records in U.S. Bureau of Transportation Statistics.

Research questions

What are the characteristics of airports, time of day, day of week, and distances most correlated with longer delays?

What are the origin airports, destination airports, and common routes that experience longest average delays?

How effective is basic flight characteristics in prediction whether a particular flight will be delayed by more than 30 minutes?

Dataset

The final dataset consists of 10,000 rows and five original columns:

date: flight date and time

delay: flight delay in minutes

distance: flight distance in miles

origin: origin airport code

destination: destination airport code

The data is distributed by Vega Datasets as flights-10k.json. The repository also contains flight_sample.csv that allows reproduction
of the analysis with the same dataset. The script download_data.py allows downloading the same 10,000-flight dataset again.

Files

download_data.py: Downloads flights-10k.json and stores it in flight_sample.csv file.

flight_sample.csv: 10,000-flight dataset that was used in the final analysis.

eda.py: Loads the data, engineers variables, computes exploratory statistics, generates EDA figures and tables.

analysis.py: Implements day-of-week analysis and route analysis, trains Random Forest classifier for predicting delays longer than
30 minutes.

test_project.py: Tests feature engineering and grouped statistics implementations using both full dataset and miniature dataset.

requirements.txt: list of required Python packages.

figures/: EDA figures and CSV summary tables generated by the analysis scripts.

Setup

Install required packages:

python -m pip install -r requirements.txt

Reproduce the analysis

The repository already contains flight_sample.csv. To download new 10,000-flight dataset, execute:

python download_data.py

Check that the dataset is valid:

python -c "import pandas as pd; print(pd.read_csv('flight_sample.csv').shape)"

Expected result:

(10000, 5)

Run exploratory analysis:

python eda.py

Run final route and day-of-week analysis and Random Forest model:

python analysis.py

Both scripts will create or update files in the figures/ directory.

Tests

To run tests:

python test_project.py

You can also run tests with pytest:

python -m pytest -q

There are six tests in the final project.

Code quality

python -m flake8 eda.py analysis.py test_project.py download_data.py

Final modeling approach

The model uses origin, destination, time_of_day, day_of_week, month, hour, and distance as predictors. Categorical features
are converted to indicator variables with the help of pandas.get_dummies. The data is split into 80%/20% training and testing
sets with stratification. Random Forest with 100 trees, maximum tree depth of 10, balanced class weights and random_state=1 is 
trained to predict delay_over_30.

Important difference from EDA proposal

The original exploratory analysis was conducted based on 77 flights and used features that do not appear in the final dataset.
The final project implements the analysis based on 10,000 flights and concentrates on airport, route, schedule, distance and prediction 
patterns that are supported by the final dataset.
